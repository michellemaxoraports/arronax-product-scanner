Connection / camera help

Use this page in Safari or Chrome over HTTPS. Allow camera access when prompted. If camera access was previously blocked, open the browser's site settings and allow Camera, then reload this page. Close other camera apps before scanning.

If lookup fails, check that the Apps Script deployment is the latest version and that its access setting permits this scanner to call the read-only lookup endpoint.
